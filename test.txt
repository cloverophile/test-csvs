## Incident Timeline Summary

On **March 27, 2023**, between **14:37 and 15:01 UTC**, a security incident unfolded on host **DESKTOP-887GK2L** under the account **CyberJunkie**. The incident began with multiple successful logon events (Event ID 4624) recorded in the Security log between 14:37 and 14:38, suggesting either repeated authentication attempts or session establishment. Shortly after, at **14:42**, Windows Defender triggered a series of alerts (Event IDs 1116 and 1117), indicating that malware or a threat was **detected and then acted upon**. At **14:44**, Windows Firewall configuration changes were logged (Event ID 2004), suggesting the firewall rules were being modified — potentially to allow malicious traffic. By **14:50–14:51**, audit policy changes (Event ID 4719) and a scheduled task creation (Event ID 4698) were recorded, classic indicators of an attacker attempting to **establish persistence and cover their tracks**. Finally, at **14:58**, multiple **suspicious PowerShell** executions (Event ID 4103) were flagged, pointing to script-based post-exploitation activity, followed at **15:01** by a Windows Firewall service stop event (Event ID 104), likely to disable host-based defenses and facilitate further intrusion.
